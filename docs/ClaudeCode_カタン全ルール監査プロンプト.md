# 0. 目的
このリポジトリのシナリオ・ルールに公式との乖離がある（特に航海者）。
基本ゲーム・都市と騎士・航海者の全シナリオ／全ルールを、下記「公式リファレンス（§4）」を
唯一の正として1項目ずつ突き合わせ、(1)監査ドキュメント化 → (2)乖離を優先度順に修正する。

# 1. 鉄則（必ず守る）
- 既存テストは常に全て緑を維持。修正のたびに実行して確認する。
- コアエンジン（基本ルール）の挙動は、公式と一致している限り変えない。回帰を出さない。
- 各修正は「何を・なぜ」のコミットメッセージで小さく分割。
- 大きいタスクなので段階実行。各フェーズ完了時に git チェックポイントを切り、進捗を要約報告。
- 公式の「地図タイル座標」は画像でしか厳密に分からない。座標の厳密一致は推測で埋めず、
  コンポーネント構成（各ヘックス種別の枚数・金の数・港の数）と固有ルール・勝利条件を正とし、
  厳密な座標配置が必要な箇所は監査ドキュメントに「TODO（要地図画像）」として明記する。
- リポジトリ既存の CLAUDE.md / 命名規約 / テスト方針に従う。

## 4.3 航海者 — 共通ルール（全シナリオ共通・チェックリスト）
- 船: コスト=木1+羊1。海辺（片側が海ヘックスの辺）に配置。自分の船 or 建物に接続（道には直結しない）。
      相手建物を超えない。海賊隣接辺に新規配置不可。船は15隻。
- 船の移動: アクションフェイズに1ターン1隻。端が「オープン」（自分の船/建物に隣接しない端）のみ移動可。
      そのターン建てた船は不可。自分の建物2つを結ぶ連続船列（closed、相手が分断しても）は不可。海賊辺へ/から不可。
- 金（gold）: 数字一致で、隣接する 開拓地ごとに任意資源1枚 / 都市ごとに任意資源2枚（自由に組合せ）。「金」資源カードは無い。
- 海賊（pirate）: 7 or 騎士で「盗賊か海賊のどちらか」を動かす。海賊は枠/海ヘックスへ。海ヘックスならその辺に船を持つ相手1人からランダム1枚強奪。海賊隣接辺は船の新規配置・移動不可。
- 最長交易路: 「最長の道」改め。道+船の連続5本以上で2点。道と船は「自分の建物」で接続している時のみ同一ルート扱い（空き交差点では道↔船は繋がらない）。
- 発展カード変更: 街道建設=道2/船2/道1+船1。騎士=「盗賊か海賊を動かす」。
- セットアップ: 海フレームを組む。海岸の開拓地は道の代わりに隣接空き海辺へ船1隻を置ける。
→ §5に既知の乖離あり。実装の現状を AUDIT_SEAFARERS.md に ✅/⚠️/❌ で記録。

## 4.4 航海者 — シナリオ（公式8＋New World）
※ 勝利条件・固有ルールが最重要。コンポ枚数は3人用目安（最終確定は要地図画像、§1鉄則に従う）。
※ 現実装のオリジナル（群島/黄金諸島/連なる島々/大連邦）は公式シナリオに置換する。

S1 新たな海岸を目指して
  勝利14。本島（最大の陸塊）＋小島“複数”（各1〜3マス、本島と1海ヘックスで隔てる）。初期配置は本島のみ。
  固有: 小島に初めて開拓地を建てるたび+2点（島ごと、他人が先でも可）。
  コンポ(3人): 総35（海13/金2/丘4/森3/牧草5/畑4/山4）。数字22。港 2:1×5・3:1×3。
  実装: データ中心。islands.ts の新島ボーナスを+2で流用。

S2 4つの島
  勝利13。ホーム島1〜2＋“各プレイヤーにとって”未探検の島。
  固有: 未探検の島に初開拓地ごとに+2点（未探検はプレイヤー別state）。
  コンポ(3人): 総35（海15/金0/各資源4ずつ）。数字20。港 2:1×5・3:1×4。

S3 霧の島
  勝利12。一部ヘックス＋数字を“裏向きスタック”にして探索で公開。
  固有: 船/道を「空きヘックスに隣接する交差点」に置くと最上段を公開。陸→ランダム数字+その地形資源1枚を即取得／海→なし。
  コンポ(3人): 表30＋裏12。数字 表14＋裏10。
  実装: 新機構（裏向きヘックス state＋配置時の探索フック onExplore）。

S4 砂漠を越えて
  勝利14。“大きな砂漠が本島を分断”。砂漠を迂回 or 海を渡って拡張。
  固有: 未探検地域に初開拓地ごとに+2点。
  コンポ(3人): 総35（海10/金2/砂漠3/丘3/森5/牧草4/畑4/山4）。数字22。港 2:1×5・3:1×3。
  実装: データ中心。※現実装の「遠い金の島」版は別物。砂漠帯で陸を割る構成に作り直す。

S5 忘れられた部族
  勝利13。海の辺に VPトークン/開発カード/港 を事前配置。
  固有: 船を建設・移動してその辺に到達で取得（VP=1点／カード=即購入扱い／港=自分の海岸開拓地隣に設置）。
        開拓地は“数字ディスクのあるヘックス”のみ。盗賊も数字ヘックスのみ。
  コンポ: 金2。VPトークン8（辺上）・開発カード4（辺上）。港ランダム。
  実装: 新機構（辺トークン state＝vp|dev|harbor、船建設/移動完了時に回収 seaEdgeTokens、配置制約）。

S6 カタンの織物
  勝利14、または“5村以上が供給切れ”になった時点で最多VP（同点は織物多い方）。
  固有: 小島の村（数字）に自分の建物から航路接続で織物トークン取得（接続時1枚＋村の数字が出るたび接続者全員1枚、各村5枚）。織物2枚で1点。
        開始時 開拓地3つ（最初の2つは資源なし、3つ目で取得）。小島に開拓地不可。最長交易路タイル不使用。
  コンポ: 織物50。村8（小島4つに数字）。
  実装: 新機構（cloth/village state、生産に村→織物、startingSettlements=3、useLongestRoute=false、scoring織物ペア、終了二系統）。

S7 海賊の島々 ← 最重量・別ゲーム級
  勝利=自分の海賊要塞を制圧 かつ 10点以上。
  固有: 海賊艦隊が固定経路を自動移動（ダイス後・資源収集前に2個の小さい目の数だけ前進）。自分の建物に隣接停止で即攻撃
        （海賊強さ=その目、自分強さ=軍船数。海賊が強い→ランダム1枚+都市ごと1枚破棄／自分が強い→任意1枚／同点→なし）。
        軍船=騎士カードで起点に近い通常船を1隻軍船化。本島→自色ビーチヘッド→自色要塞へ“分岐なし最短1本道”。
        要塞は海賊ラホ3トークン、全除去で奪取。盗賊・最長交易路・最大騎士力 全て不使用。7=破棄+強奪のみ。
  実装: 専用モジュール engine/pirateIslands.ts 推奨（艦隊移動・戦闘・軍船・要塞HP・専用勝利条件）。

S8 カタンの七不思議
  勝利=不思議を完成、または 10点以上 かつ 他の誰より高いレベルまで建設。
  固有: 5種の不思議タイル（建設要件あり・1人1つ早い者勝ち）。4レベル制・各レベル資源5つ・Lv4で完成。
        小島に初開拓地ごとに+1点。海賊不使用。
  実装: 専用モジュール engine/wonders.ts（要件判定・レベル建設・勝利条件）。

New World（自由構築）
  勝利12。ヘックス自由配置の自作マップ。未探検島に初開拓地ごとに+1点。
  実装: 制約付きランダム生成（赤6/8隣接回避・金に赤数字を置かない）。島ボーナス流用。
