# カタン航海者版（Seafarers）ルール・シナリオ仕様メモ

> 出典: 公式ルールブック 第6版（CATAN Studio, 2025）
> 前提: カタン基本ルールは既知。**基本との差分**にフォーカス。

---

## 1. 全シナリオ共通の追加ルール

### 船 (Ship)
- **コスト: 木材1 + 羊毛1**（道は木材1+レンガ1）
- 配置先は「少なくとも片側が海ヘクス」の辺
- 接続条件: 自分の **船** または **建物（開拓地/都市）** に隣接していること。**道には直接つながらない**
- 相手の建物を超えて延ばせない（道と同じ距離ルール）
- 海賊がいるヘクスの辺には新規配置不可
- 分岐は自由（自分のネットワークから何本でも枝分かれ可）
- 初期配置で海岸に開拓地を置く場合、道の代わりに隣接する空き海辺へ船1隻を置ける

### 船の移動 (Move a Ship)
アクションフェイズに **1ターン1隻まで** 移動可。制約:
1. そのターンに建てた船は動かせない
2. 端が「オープン」な船のみ移動可。**オープン = その端が自分の船/建物に隣接していない**
3. 自分の建物2つを結ぶ連続した船列の一部は動かせない（"closed"）。**相手が間に建物を建てて分断しても closed のまま動かせない**
4. 海賊のいるヘクスの辺へ/から移動不可
5. 移動 = 現在地から除去し、通常の配置ルールで新しい場所へ

### 黄金の海 (Gold Field)
- 新地形。数字が出たら隣接する建物に応じて産出:
  - **開拓地ごとに 任意資源1枚**
  - **都市ごとに 任意資源2枚**（5種を自由に組み合わせ）
- 「金」という資源カードは存在しない（任意資源に変換するだけ）
- 原則、赤数字（6/8）は黄金の海に置かない

### 海賊 (Pirate)
- 盗賊の海バージョン。**7を出す or 騎士を使う** → 盗賊か海賊の **どちらか** を動かせる
- 海賊は「枠（フレーム）」または海ヘクスへ移動
- 海ヘクスに置いた場合、そのヘクスの辺に船を持つ相手1人からランダム資源1枚を奪う
- 海賊隣接辺では船の新規配置・移動が不可
- 港には干渉しない。開拓地の建設も妨げない

### 最長交易路 (Longest Route)
- 「最長の道」→「最長交易路」に改名。**道+船の連続5本以上で2VP**
- **道と船は「自分の建物」で接続している場合のみ同一ルートとして連続扱い**
- 空き交差点では道↔船はつながらない（建物がそこに必要）

### 開発カードの変更
- **街道建設**: 道2本 / 船2隻 / 道1+船1 のいずれか
- **騎士**: 効果が「盗賊か海賊を動かす」に変更

### セットアップ共通
- 基本ゲームの枠6枚を **裏返して海面側を表** にし、航海者版の枠と合わせてシナリオのマップ通りに組む
- 一部シナリオは港を裏向きランダム配置（マップ上の「?」表記）

## 2. シナリオ一覧（第6版）

構成: **基本ルール中心（1〜4, 簡単）** → **固有ルール追加（5〜8, 複雑）** → **New World（自由構築）**

各シナリオは固有のマップ・勝利VP・追加ルールを持つ。3人用と4人用でマップ/コンポーネント数が異なる。

| # | シナリオ | 勝利VP | コア追加要素 |
|---|---------|:---:|---|
| 1 | 新たな海岸を目指して | 14 | 小島入植で+2VP |
| 2 | 4つの島 | 13 | 未探検島で+2VP（プレイヤー別） |
| 3 | 霧の島 | 12 | 裏向きヘクスの探索公開 |
| 4 | 砂漠を越えて | 14 | 未探検地域で+2VP |
| 5 | 忘れられた部族 | 13 | 海上トークン/カード/港の回収 |
| 6 | カタンの織物 | 14※ | 村との交易で織物→VP |
| 7 | 海賊の島々 | 10※ | 海賊艦隊AI・戦闘・要塞攻略 |
| 8 | カタンの七不思議 | 完成 or 10 | 不思議の建設レース |
| – | New World | 12 | 自作マップ |

### シナリオ1: 新たな海岸を目指して (Heading for New Shores)
- 本島 + 複数の小島。**初期開拓地は本島に配置**
- **小島に初めて開拓地を建てるたびに +2VP**（島ごと。他人が先に建てていても獲得可）
- 勝利: 14VP

### シナリオ2: 4つの島 (The Four Islands)
- 1〜2の「ホーム島」からスタート、残りは **各自にとって** 未探検
- **未探検の島に初開拓地ごとに +2VP**
- 実装注意: 「未探検」は**プレイヤー別state**（ホーム島は人によって異なる）
- 勝利: 13VP

### シナリオ3: 霧の島 (The Fog Islands)
- 一部ヘクスと数字ディスクを**裏向きスタック**にして探索で公開
- 船/道を「空きヘクスに隣接する交差点」に置くと、スタック最上段を表に:
  - 陸ヘクス → ランダム数字ディスク + その地形の資源1枚を即獲得
  - 海ヘクス → 数字も資源もなし
- 実装注意: 隠れヘクスの山、建設時の隣接トリガー判定
- 勝利: 12VP

### シナリオ4: 砂漠を越えて (Through the Desert)
- 砂漠が大きな島を分断。隣の島へ渡るか砂漠を越えて拡張
- 初期開拓地は本島側。小島と砂漠の向こうの細い陸地が「未探検地域」
- **未探検地域に初開拓地ごとに +2VP**
- 勝利: 14VP

### シナリオ5: 忘れられた部族 (The Forgotten Tribe)
- 海の辺に **VPトークン / 開発カード / 港** が事前配置される
- 船を建設 or 移動してその辺に到達すると獲得:
  - VPトークン → 1VP
  - 開発カード → 今ターン購入扱い（次ターン以降使用 or 即勝利公開可）
  - 港 → 自分の海岸開拓地の隣に配置（港同士は1辺以上空ける。置けなければ手元保留）
- **数字ディスクのあるヘクスにしか開拓地を建てられない**。盗賊も数字ヘクスにしか動かせない
- 勝利: 13VP

### シナリオ6: カタンの織物 (Cloth for Catan)
- 小島の「村」（数字ディスク）に自分の建物から航路をつなぐと **織物トークン** 獲得:
  - 接続成立時に即1枚
  - 生産フェイズで村の数字が出たら、接続済みの各プレイヤーが1枚ずつ
  - 村の供給（各5枚）が尽きたらその村は生産停止
  - **織物2枚ペアで1VP**（端数は0VP）
- 開始時は **開拓地3つ** 配置。最初の2つは資源なし、3つ目で資源獲得
- 小島には開拓地建設不可。**最長交易路タイルは不使用**
- 村につなぐ航路は "closed" 扱い（その船は動かせないが延長/分岐は可）
- 海賊は最初の村接続を作るまで動かせない。移動時は資源か織物を強奪
- 勝利: **14VP** または **5村以上が供給切れになった時点で最多VP**（同点は織物が多い方）

### シナリオ7: 海賊の島々 (The Pirate Islands)
※ 別ゲームに近い。実装難度高。バリアント非推奨。
- **海賊艦隊が中央の固定経路を自動移動**。ダイスを振った後・資源収集の前に、**2個のダイスの小さい方の目** の数だけ移動（ゾロ目はどちらでも）
- 艦隊が自分の建物に隣接して停止したら**即攻撃**:
  - 海賊の強さ = 移動に使った目
  - 自分の強さ = **軍船** の数
  - 海賊が強い → ランダム資源1枚 + 都市ごとに1枚を捨てる
  - 自分が強い → 任意資源1枚獲得 / 同点 → 何も起きない
- **軍船**: 騎士カード公開で、起点開拓地に最も近い「通常船」を1隻軍船化（騎士は軍船化専用に変更）
- 各自、本島の海岸建物 →（自色ビーチヘッド）→ 自色の海賊要塞 へ **分岐なしの最短1本道** で船を延ばす（他人を妨害する遠回り不可）
- 要塞到達後に攻撃。3つの海賊ラホトークンを全除去で要塞奪取 → 以後は自分の開拓地扱い（都市昇格可）
- **盗賊・最長交易路・最大騎士力は不使用**。7は「半分捨て + 強奪」のみ
- 勝利: **自分の要塞を制圧 かつ 10VP以上**

### シナリオ8: カタンの七不思議 (The Wonders of Catan)
- 5種類の「不思議」タイル。建設要件を満たすとクレーム（**1人1つ・早い者勝ち**）
  - 要件の例: 2都市が必要 / 港の都市+5本以上の交易路 / 1都市+6VP など
- **4レベル制**。各レベルとも同じ資源5つ。1ターンに払える分だけ複数レベル建設可。レベル4で完成
- 小島に初開拓地ごとに +1VP
- 海賊は不使用
- 勝利: **不思議を完成** または **10VP以上 かつ 他の誰より高いレベルまで建設**

### New World（自由構築バリアント）
- ヘクスを自由配置で自作マップ。島の数/大きさを相談で調整可
- 未探検の島に初開拓地ごとに +1VP
- 勝利: 12VP

## 3. 実装の勘所（既存カタンエンジン拡張の観点）

- **船は道とは別ピース型**だが、最長交易路の探索は既存の「最長の道」グラフロジックを拡張するのが素直。エッジ集合に船を加え、ただし**道セグメント↔船セグメントの接続は「自分の建物ノード」経由のときだけ連結**として扱う
- **open/closed 判定** = ルート端ノードに自分の建物が無く、かつその端から先に自分のピースが無ければ open。船移動の可否はこれで決まる
- **海賊は2つ目の robber エンティティ**。7/騎士発動時に `target: 'robber' | 'pirate'` を選ばせるフロー。海賊は海ヘクスのみ、盗賊は陸ヘクスのみ
- **黄金の海**は生産処理に「任意資源を選ぶ」UIステップを挟む（開拓地=1, 都市=2）
- **シナリオはデータ駆動で分離**すると拡張しやすい。共通エンジン + シナリオごとに以下をフックで差し込む:
  - マップ定義（ヘクス/数字/港の初期配置、本島・小島の区別）
  - 勝利VP閾値と特殊勝利条件
  - 追加ルールフック（探索公開・VP/織物/港トークン回収・要塞戦闘・不思議建設）
- **「未探検島」はプレイヤー別state**（シナリオ2・4・New World）。盤面共有stateとは別に持つ
- まずは **シナリオ1（新たな海岸を目指して）** だけ実装するのが定石。船・船移動・小島入植VPだけで完結し、複雑な固有ルールが無いのでエンジンの土台を固められる
- C&K と航海者版は公式に互換。既存の都市と騎士実装があるなら、最終的に両対応も視野に入る

## 4. 最小実装ロードマップ（提案）

1. **船ピース + 配置ルール**（海辺判定・接続・距離）→ シナリオ1マップ
2. **最長交易路**（道+船、建物経由の連結判定）
3. **船の移動**（open/closed 判定）
4. **海賊**（7/騎士での盗賊・海賊選択、隣接船からの強奪）
5. **黄金の海**（任意資源産出）
6. **小島入植VP + 勝利14VP** → シナリオ1完成
7. 以降、シナリオ2→3→4（探索系）→ 5〜8（固有ルール）の順で追加
