# カタン航海者版 公式準拠リビルド計画

対象リポジトリ: `ankake-web/catan`
出典: 公式ルールブック第6版（CATAN Studio, 2025）

---

## 0. 方針

- **コアは流用、いじらない**。船・船移動（open/closed）・金（開拓地1/都市2の任意資源）・海賊・最長交易路（道+船、建物経由連結）は既に公式準拠。
- **変えるのは2点だけ**:
  - **(A) 盤面レイアウトの公式化** — 今のオリジナルマップ（群島/黄金諸島/連なる島々/大連邦）を、公式8シナリオに置換。
  - **(B) シナリオ固有ルールのフック追加** — 探索・トークン回収・織物・海賊艦隊・不思議 を差し込める機構を作る。

> ⚠️ **盤面座標について**: 公式マップのタイル配置は、ルールブックの**地図画像**でしか厳密には分からない。本計画は公式の「コンポーネント構成・勝利条件・固有ルール」を正とし、デジタル版として忠実な盤を組む前提。ピクセル単位で公式マップと一致させたい場合は、ルールブックの各シナリオ地図画像を共有してくれれば座標まで合わせられる。
> ※ 下記コンポーネント数はOCR由来のため誤差の可能性あり。**勝利条件と固有ルールは信頼できる**。コンポ数は最終的に地図画像で照合推奨。

## 1. アーキテクチャ変更（基盤 / Phase 1 で導入）

### Scenario interface 拡張（`src/engine/scenarios.ts`, `src/types.ts`）

1. **盤 footprint をシナリオごとに**
   現状は全航海者シナリオが固定の `getHexRegion(3,2,3)` を使い回し → 盤外に余分な海が出る。各シナリオが「land + 明示的な sea」の集合だけを footprint として返すように変更（`buildFromLandMap` は活かす）。

2. **`rules?` フックを追加**（型だけ先に定義、各フェーズで実装を差し込む）
   ```ts
   interface ScenarioRules {
     startingSettlements?: number;   // 既定2。織物=3
     useLongestRoute?: boolean;      // 既定true。織物/海賊の島々=false
     useRobber?: boolean;            // 既定true。海賊の島々=false
     newIslandBonusVp?: number;      // 新島初入植VP（0=無効, 1, 2）
     onExplore?: ExploreHook;        // 霧の島：裏向きヘックス公開
     seaEdgeTokens?: SeaEdgeTokenSpec; // 忘れられた部族：海上VP/カード/港
     clothTrade?: ClothSpec;         // 織物：村との交易
     pirateFleet?: PirateFleetSpec;  // 海賊の島々：艦隊移動・戦闘
     wonders?: WonderSpec;           // 七不思議
   }
   ```
   `game.ts` / `actions.ts` の該当ポイント（配置時・生産時・ダイス後・勝利判定）から、存在すればフックを呼ぶ形にする。

## 2. フェーズ別ロードマップ

| Phase | 内容 | 主な追加機構 |
|:---:|---|---|
| **1** | 基盤（footprint＋ルールフック）＋ **S1 新たな海岸**＋全シナリオ勝利点修正 | Scenario拡張・島ボーナス流用 |
| **2** | **S2 4つの島**・**S4 砂漠を越えて** | データのみ（島ボーナス系） |
| **3** | **S3 霧の島** | 裏向きヘックス探索 |
| **4** | **S5 忘れられた部族** | 海辺トークン回収・配置制約 |

## 3. 各シナリオ公式データ（実装の正）

> 勝利条件・固有ルールが最重要。コンポ数は目安（3人用基準、地図画像で要照合）。

### S1 新たな海岸を目指して（Heading for New Shores）
- **勝利: 14VP**
- 本島（最大の陸塊）＋小島複数。初期配置は本島。
- **固有ルール: 小島に初めて開拓地を建てるたび +2VP**（島ごと、他人が先でも可）
- コンポ目安: 計35（海13/金2/丘4/森3/牧草5/畑4/山4）、数字22、港 2:1×5・3:1×3
- 実装: **データのみ**。`islands.ts` の `newIslandBonusRep`(+2) をそのまま流用。`scenarios.ts` にマップ＋`victoryTarget:14`。

### S2 4つの島（The Four Islands）
- **勝利: 13VP**
- 1〜2のホーム島スタート、残りは**各自にとって未探検**（プレイヤー別state）。
- **固有ルール: 未探検の島に初開拓地ごとに +2VP**
- コンポ目安: 計35（海15/金0/丘4/森4/牧草4/畑4/山4）、数字20、港 2:1×5・3:1×4
- 実装: **データのみ**。ホーム島がプレイヤーごとに異なる点に注意（`isUnclaimedNewIslandVertex` の home 判定をプレイヤー別に拡張）。

### S3 霧の島（The Fog Islands）
- **勝利: 12VP**
- 一部ヘクスと数字を**裏向きスタック**にして探索で公開。
- **固有ルール（探索）**: 船/道を「空きヘクスに隣接する交差点」に置くと最上段を表に。陸→ランダム数字＋その地形の資源1枚を即取得／海→何もなし。
- コンポ目安: 表30（海16/丘2/森4/牧草4/畑2/山2）＋裏12（海2/金2/丘2/森1/牧草1/畑2/山2）、数字 表14＋裏10
- 実装: **新機構**。`types.ts` に裏向きヘックス状態。配置アクション（`actions.ts`/`game.ts`）で隣接する空きヘクスを検出→公開（`onExplore`）。renderer に霧表示。

### S4 砂漠を越えて（Through the Desert）
- **勝利: 14VP**
- **砂漠が島を分断**。本島側で初期配置。砂漠の向こうの細い陸地＋小島が未探検地域。
- **固有ルール: 未探検地域に初開拓地ごとに +2VP**
- コンポ目安: 計35（海10/**金2/砂漠3**/丘3/森5/牧草4/畑4/山4）、数字22、港 2:1×5・3:1×3
- 実装: **データ中心**。※現状の「遠い金の島」版とは別物。砂漠帯で陸を割る構成に作り直す。島ボーナス流用。

### S5 忘れられた部族（The Forgotten Tribe）
- **勝利: 13VP**
- **固有ルール**:
  - 海の辺に **VPトークン / 開発カード / 港** が事前配置。船を建設・移動してその辺に到達で取得（VP=1点／カード=即購入扱い／港=自分の海岸開拓地隣に設置）。
  - **数字ディスクのあるヘクスにしか開拓地を建てられない**。盗賊も数字ヘクスのみ。
- コンポ目安: 計49（海19/金2/砂漠3/各資源5）、**VPトークン8（辺上）・開発カード4（辺上）**、港ランダム
- 実装: **新機構**。`types.ts` に「辺トークン」state（種別=vp|dev|harbor）。`actions.ts` の船建設/移動完了時に辺トークン回収（`seaEdgeTokens`）。配置バリデーションに「数字ヘクスのみ」制約。

### S6 カタンの織物（Cloth for Catan）
- **勝利: 14VP**、または**5村以上が供給切れになった時点で最多VP**（同点は織物多い方）
- **固有ルール**:
  - 小島の**村**（数字ディスク）に自分の建物から航路接続で**織物トークン**取得（接続時1枚＋村の数字が出るたび接続者全員に1枚、各村5枚）。**織物2枚ペアで1VP**。
  - **開始時 開拓地3つ**（最初の2つは資源なし、3つ目で取得）。小島には開拓地建設不可。**最長交易路タイル不使用**。
- コンポ目安: 計42、**織物トークン50**、村8（小島4つに数字）
- 実装: **新機構**。`types.ts` に cloth/village state。生産処理に「村数字→接続者へ織物」を追加。`rules.startingSettlements=3` / `useLongestRoute=false`。scoring に織物ペア加点。終了条件の二系統化。

### S7 海賊の島々（The Pirate Islands）← 最重量
- **勝利: 自分の海賊要塞を制圧 かつ 10VP以上**
- **固有ルール**:
  - **海賊艦隊が中央の固定経路を自動移動**（ダイス後・資源収集前に「2個の小さい目」分だけ前進）。自分の建物に隣接停止で即攻撃（海賊強さ=目、自分強さ=軍船数）。
  - **軍船**: 騎士カードで起点に近い通常船を1隻軍船化。
  - 各自、本島→自色ビーチヘッド→自色要塞へ**分岐なし最短1本道**。要塞は海賊ラホトークン3つ、全除去で奪取。
  - **盗賊・最長交易路・最大騎士力 全て不使用**。7は半分捨て＋強奪のみ。
- コンポ目安: 計49、海賊ラホトークン12、要塞4
- 実装: **専用モジュール** `engine/pirateIslands.ts` 推奨。艦隊移動・戦闘・軍船・要塞HP・専用勝利条件。`useRobber=false`/`useLongestRoute=false`/largestArmy無効。

### S8 カタンの七不思議（The Wonders of Catan）
- **勝利: 不思議を完成、または 10VP以上 かつ 他の誰より高いレベルまで建設**
- **固有ルール**:
  - 5種の不思議タイル（建設要件あり、1人1つ早い者勝ち）。**4レベル制・各レベル資源5つ**。レベル4で完成。
  - 小島に初開拓地ごとに +1VP。海賊不使用。
- コンポ目安: 計49、不思議タイル5
- 実装: **専用モジュール** `engine/wonders.ts`。要件判定・レベル建設・勝利条件。

### New World（自由構築）
- **勝利: 12VP**。ヘクス自由配置の自作マップ。未探検島に初開拓地ごとに +1VP。
- 実装: 制約付きランダム生成（赤数字隣接回避・金に赤数字を置かない）。島ボーナス流用。

## 5. 次フェーズの着手単位（参考）

各フェーズも同じ粒度で貼り付けブロック化できる。固有ルールの新機構が要るのは **S3（探索）/ S5（辺トークン）/ S6（織物）/ S7（艦隊戦）/ S8（不思議）** の5つ。データ中心で軽いのは **S1/S2/S4/New World**。重いS7・S8を最後に回す構成。
